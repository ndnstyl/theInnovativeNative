# Excalidraw Scenes — Marketing Un-Silo Video

12 pre-built scenes, in order of appearance in `script.md`. Each scene is a separate Excalidraw file. Recommended naming: `unsilo-S01-five-questions.excalidraw`, etc.

## Brand cheat sheet (Excalidraw color picks)

| Use | Hex | Excalidraw stroke choice |
|---|---|---|
| Primary structure | **#00FFFF cyan** | Custom hex picker, "Sharp" stroke |
| Warning / broken / RARE | **#FF00FF magenta** | Custom hex picker |
| Neutral text | white / very light gray | Default |
| Background | black | Theme → Dark |
| Fill (when needed) | hachure fill, low opacity | Excalidraw default |

Font: Excalidraw's **Cascadia Code** (mono) for technical labels, **Virgil** (hand) for callouts and emphasis. Use Virgil for the title of every scene.

Canvas: default 16:9. Zoom to fit before recording each scene.

## Save & Export workflow

1. Build all 12 scenes ahead of recording. Don't draw them live — recreate them live for the camera.
2. Save each as `.excalidraw` (JSON, version-controllable) AND export PNG at 4x for thumbnails / shorts overlays.
3. Folder: `/Users/makwa/theinnovativenative/content/handouts/marketing-unsilo/excalidraw/`
4. While recording, keep all 12 `.excalidraw` files open in tabs. Switch between them via Cmd+Tab.

## During the shoot

- Slow down on the reveals. The hand-drawn aesthetic only sells if the viewer sees the build.
- Use Excalidraw's library feature to pre-save shapes you reuse (the table box, the labeled circle).
- After each scene, pause two seconds before cutting to the next. That gives the editor clean handles.
