# VisionSpark RE — Brand System

## Brand Philosophy

VisionSpark RE is a real estate AI marketing product that gives agents and developers access to true generative video — not the Ken Burns pan-and-zoom that every other tool calls "AI video." The brand communicates technical authority without tech-bro posturing. It speaks to real estate professionals who are overwhelmed by AI tool fragmentation but know they need to adopt or fall behind.

The brand sits at the intersection of **proptech credibility** and **operator pragmatism**. It does not oversell. It shows.

## Color System

| Token | Hex | Role |
|-------|-----|------|
| Deep Slate Blue | `#1B3A4B` | Primary text, headers, trust elements |
| Warm Terracotta | `#D4956A` | Accent, CTAs, highlights, pricing badges |
| Off-White | `#F5F0EB` | Background, breathing space |
| Muted Slate | `#4A6B7A` | Secondary text, captions |
| Warm Brown | `#8B6F5C` | Tertiary accent, subtle borders |
| Pure White | `#FFFFFF` | Cards, overlays |

### Usage Rules

- Deep Slate Blue for all headings and primary body text
- Warm Terracotta for CTAs, price callouts, and emphasis elements only — never for body text
- Off-White backgrounds create premium feel without the sterility of pure white
- Never use more than 2 accent colors in a single composition
- Dark mode variant: invert Off-White → Deep Slate Blue, Deep Slate Blue → Off-White

## Typography

| Role | Font | Weight | Size Range |
|------|------|--------|------------|
| Display / H1 | DM Serif Display | 400 | 48-72px |
| Section Headers / H2 | DM Serif Display | 400 | 32-40px |
| Subheadings / H3 | Inter | 600 | 20-24px |
| Body | Inter | 400 | 16-18px |
| Captions / Labels | Inter | 500 | 12-14px |
| Code / Technical | JetBrains Mono | 400 | 14px |

### Typography Rules

- DM Serif Display creates the "established, trustworthy" feel appropriate for real estate
- Inter provides clean readability for longer copy
- Never use more than 2 font families in a single layout
- Line height: 1.6 for body, 1.2 for headings
- Letter spacing: -0.02em for DM Serif Display headings, 0 for Inter body

## Signature Elements

- **Terracotta accent bars**: 3px left-border on feature cards and callout boxes
- **Slate blue dividers**: Thin (1px) horizontal rules between sections
- **Warm glow**: Subtle radial gradient using `rgba(212, 149, 106, 0.08)` behind hero and CTA sections
- **Trust badges**: Slate blue background with off-white text, rounded corners (8px)
- **Price callouts**: Terracotta background with white text, slightly rounded (4px)

## Photography Direction

- Property interiors: bright, naturally lit, high-end staging
- Before/after comparisons: left-right split with thin terracotta divider
- Demo screenshots: browser chrome mockup with subtle drop shadow
- Never use stock photos of agents shaking hands or pointing at houses
- AI-generated property images should be clearly labeled as demonstrations
