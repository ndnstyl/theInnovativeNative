# /goal — Domain-Routed Autonomous Execution

The single entrypoint that turns an objective into shipped work by pulling the right context, skills, workflows, and agents for its domain. It is the top layer over the existing spine (auto-memory vault + OB1 + skills + n8n fleet + mechanical subagents). It is **data-driven**: behavior comes from `.claude/systems/`, not from this file — so adding a domain never means editing this skill.

## Inputs it reads (canonical)

- `.claude/systems/registry.yaml` — domain index + global `defaults` (autonomy, gates, agents).
- `.claude/systems/SCHEMA.md` — the manifest contract.
- `.claude/systems/<domain>.yaml` — the System Pack for each matched domain.
- `.claude/systems/n8n-fleet.json` — resolve workflow IDs → name/status/domain (generated by `scripts/systems/build-fleet.sh`; if stale, re-run it).
- The vault mirror (`memory/system_*.md`, `memory/n8n_*.md`) is for the human; you read the YAML, not the mirror.

## Execution protocol

### 1. Classify
Read `registry.yaml`. Match the goal text against each domain's `entrypoints` (in its manifest) and the trigger phrases of its `skills`. Produce a ranked list of domains.
- One clear domain → proceed.
- Two or more plausible domains (cross-domain goal, e.g. "make a launch video AND the email sequence") → load BOTH packs; the goal decomposes across them.
- Genuinely ambiguous (can't tell which) → `AskUserQuestion` ONCE to pick the domain, then proceed. Do not ask twice.

### 2. Load the pack(s)
For each matched `<domain>.yaml`:
- Read every `brand_rules` page from the auto-memory vault. These are **hard constraints** — carry them verbatim into every delegation.
- Read every `memory_anchors` page — this is the domain working context.
- Resolve each `n8n_workflows` ID against `n8n-fleet.json` (skip any whose status is `superseded`/`archived`; flag if a referenced ID is missing).
- Note the pack's `skills`, `agents`, `autonomy`, `gates`, `verification`.

### 3. OB1 recall
Query OB1 for prior thoughts matching the goal's domain + nouns (reuse the pattern in `scripts/hooks/ob1-inject.sh`). Fold the top hits into the working context. Skip silently if OB1 is unreachable.

### 4. Plan + delegate
- If the goal is **build-shaped** (ships code / a durable artifact), generate a lightweight spec first via `.specify/` ("No Spec Kit = No Work").
- Hand decomposition to the `orchestrator` agent. Each delegation MUST: start with the `[task_type=X]` tag (agent-protocol), follow CTCO, and prepend the pack's `brand_rules` as CONSTRAINTS. Use only the pack's mechanical `agents` — never persona-skills as executors.
- Parallelize independent subtasks.

### 5. Execute at the declared autonomy — but HARD-STOP at gates
- `autonomy: full_ship` → execute, verify, capture without asking.
- `autonomy: approve_first` → present the plan, wait for one-tap approval, then execute.
- **Gates fire regardless of autonomy.** Before any gated action, STOP and hand to Mike:
  - `n8n_activation` — never activate/test a workflow yourself. Run the `n8n-check` skill, deploy the JSON if asked, then hand to Mike to activate + test. He is the only tester (n8n-rules).
  - `outward_send` — email, social post, publish to a live audience: draft it, show it, ask before sending.
  - `payment_mutation` / `prod_deploy` / `db_migration` — confirm before executing; check for existing data first (security-rules).

### 6. Verify
Run the pack's `verification` list against the output. For content, that includes the universal brand checks (no em dashes incl. `&mdash;` entities, palette/voice). Do not declare done until verification passes; if it fails, loop back to step 4.

### 7. Capture
Invoke `distill` to write the goal's learnings to auto-memory + OB1. The session-log Stop hook handles the Airtable time/deliverable record. Report: domain(s) routed, skills/agents used, workflows touched, what shipped, what gated.

## Output contract (what you tell Mike at the end)

```
GOAL: <restated>
ROUTED: <domain(s)> (autonomy: full_ship)
LOADED: skills=[...] workflows=[...] brand_rules=[...]
SHIPPED: <artifacts + paths/links>
GATED: <anything handed back to Mike to send/activate, and why>
CAPTURED: <auto-memory + OB1 ids>
```

## Anti-patterns

- **Routing through persona-skills as executors.** Personas are context only; the lean mechanical agents do the work.
- **Asking permission inside `full_ship`** for anything that isn't a gate. If the plan passes hard-rules/security/agent-protocol, execute (feedback_execute_dont_ask).
- **Self-testing n8n.** Never. Deploy + hand off.
- **Skipping the brand_rules injection.** A delegation without the pack's constraints will drift (e.g. em dashes, wrong palette, vendor voice).
- **Treating the vault mirror as source of truth.** Edit manifests in `.claude/systems/`, then re-run `sync-vault.sh`; never hand-edit `memory/system_*.md`.
- **Stale fleet.** If `n8n-fleet.json` looks out of date (referenced ID missing), re-run `build-fleet.sh` before relying on it.
